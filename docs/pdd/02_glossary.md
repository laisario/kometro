# Glossary

This glossary defines key terms used throughout the KOMETROgo platform. Terms are organized alphabetically for easy reference.

## Core Metrological Terms

| Term | Definition |
|------|------------|
| **Acceptance Criteria** | The maximum allowable error threshold for a calibration result to be considered acceptable. Calculated as: \|Largest Error\| + \|Uncertainty\| ≤ Acceptance Criteria |
| **Calibration** | The process of comparing a measuring instrument's readings against a known reference standard and documenting any deviations |
| **Calibration Certificate** | An official document issued after calibration that records the instrument details, reference standards used, environmental conditions, and measurement results |
| **Calibration Frequency** | The defined interval between calibrations, expressed as a time period (e.g., 12 months, 6 months) |
| **Critical Analysis** | The evaluation performed by a client after receiving calibration results to determine if the instrument meets their operational requirements |
| **Largest Error** | The maximum deviation found during calibration between the instrument's reading and the reference standard value |
| **Measurement Capacity** | The range within which an instrument can perform measurements (e.g., 0-100°C for a thermometer) |
| **Measurement Uncertainty** | A parameter characterizing the range of values within which the true measurement value is expected to lie |
| **Metrology** | The science of measurement, including theoretical and practical aspects of measurements at any level of uncertainty |
| **Normative Standard** | A regulatory or industry standard that defines requirements for measuring instruments (e.g., ISO 17025, ABNT NBR) |
| **Verification (Checagem)** | A simplified check performed between calibrations to confirm an instrument is still operating within acceptable limits |

## Instrument Management Terms

| Term | Definition |
|------|------------|
| **Calibration Point** | A specific measurement value at which an instrument is tested during calibration (e.g., 25%, 50%, 75%, 100% of range) |
| **Expiration Date** | The date when an instrument's current calibration validity period ends and recalibration is required |
| **Frequency Criterion** | The method used to calculate the next calibration date: either Calendar Time (fixed intervals) or Service Time (based on actual usage) |
| **Instrument** | A base definition of a measuring device type with associated specifications, pricing, and calibration procedures |
| **Instrument Instance** | A specific physical instrument owned by a client, identified by a unique tag and serial number |
| **Instrument Position** | The current operational status of an instrument: In Use, In Stock, Inactive, Out of Service, or In Calibration |
| **Instrument Type** | A category of instruments sharing common characteristics (e.g., Pressure Gauge, Thermometer, Caliper) |
| **Sector** | A logical grouping representing a department, production line, or physical area where instruments are located |
| **Service Order** | A reference number linking a calibration to the work order or job ticket in the calibration laboratory |
| **Service Type** | Classification of calibration services: Accredited (RBC/INMETRO), Non-Accredited, or Internal |
| **Tag** | A unique identifier assigned by the client to each instrument instance for tracking purposes |

## Commercial Terms

| Term | Definition |
|------|------------|
| **Business Days** | Working days estimated for completing a calibration service, excluding weekends and holidays |
| **Delivery Address** | The physical location where calibrated instruments should be returned after service |
| **Payment Terms** | The agreed conditions for payment (e.g., 30 days net, upon delivery) |
| **Proposal** | A commercial document offering calibration services to a client with pricing, terms, and scope |
| **Proposal Revision** | An updated version of a proposal reflecting changes requested by the client or corrections |
| **Proposal Status** | The current state of a proposal: Draft, Awaiting Approval, Approved, or Rejected |
| **Service Location** | Where calibration is performed: Permanent Installation (lab), Client Site, or Outsourced |

## Document Management Terms

| Term | Definition |
|------|------------|
| **Approval** | Formal sign-off by an authorized user confirming a document revision meets requirements |
| **Document** | A controlled file such as procedures, work instructions, or policies that require versioning and approval |
| **Document Code** | A unique identifier following organizational naming conventions (e.g., PQ-001 for quality procedures) |
| **Document Status** | The lifecycle state of a document: Valid (Vigente), Obsolete (Obsoleto), or Cancelled (Cancelado) |
| **External Document** | A document not created internally, such as regulations, standards, or supplier documentation |
| **Frequency (Document)** | The defined review cycle for documents, typically expressed in years |
| **Revision** | An updated version of a document that modifies previous content while maintaining traceability |
| **Reviewer** | A user responsible for examining and updating document content during review cycles |
| **Validity Date** | The date until which a document version remains officially valid before requiring review |

## User and Access Terms

| Term | Definition |
|------|------------|
| **Client** | An organization that uses KOMETROgo to manage their instruments and documents |
| **Company** | The legal business entity associated with a client, identified by corporate registration (CNPJ) |
| **Invitation** | A secure token allowing new users to register and join an existing client organization |
| **User** | An individual with access to the KOMETROgo platform, associated with one or more client organizations |
| **User Group** | A role-based collection defining permissions (e.g., Administrator, Operator, Viewer) |

## System Terms

| Term | Definition |
|------|------------|
| **Dashboard** | A visual summary screen displaying key metrics, alerts, and status information |
| **Notification** | An automated email alert sent to users about upcoming deadlines or required actions |
| **PDF Export** | The generation of formatted documents (certificates, proposals) in Portable Document Format |
